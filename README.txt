『足立区原発 ─ 最後の制御棒 ─』 体験版  Web公開用一式
================================================================

このフォルダの中身を、そのままサーバーにアップロードしてください。
フォルダ構成は変えないでください（相対パスで参照しているため）。


■ 体験版の仕様
----------------------------------------------------------------
・プレイ範囲：第2章クリアまで
  （第2章の終了イベント → シャッター閉鎖 → 体験版終了画面）
・セーブ／ロード機能はありません
  タイトルの「続きから」とゲーム内セーブメニューは非表示です
・変異生物観測録（図鑑）は使用できます
・タイトルに「TRIAL BUILD ─ 体験版（第2章まで）」と表示されます


■ 動作環境
----------------------------------------------------------------
・PC横画面向けに作られています（スマホ縦画面は未対応）
・推奨：Safari / Chrome / Edge の最新版
・音が出ます。タイトルのクリックで音声が有効になります
・以下は外部から読み込むため、インターネット接続が必要です
    Three.js（3D描画）      cdnjs.cloudflare.com / cdn.jsdelivr.net
    Google Fonts（書体）    fonts.googleapis.com / fonts.gstatic.com


■ アップロード方法
----------------------------------------------------------------
【GitHub Pages の場合】
 1. GitHubで新しいリポジトリを作る（Public にする）
 2. このフォルダの中身をすべてアップロード
    ※フォルダごとではなく「中身」を入れてください
      （index.html がリポジトリ直下に来るように）
 3. Settings → Pages → Source を "Deploy from a branch"
    Branch は main / (root) にして Save
 4. 1〜2分待つと公開されます
    https://（ユーザー名）.github.io/（リポジトリ名）/

【レンタルサーバー等の場合】
 FTPで公開ディレクトリにこのフォルダの中身をアップロードするだけです。
 index.html が置かれた階層がそのままURLになります。


■ アクセス解析の設定（GoatCounter）
----------------------------------------------------------------
公開しただけでは計測されません。以下の設定が必要です。

 ★設定済みです。そのままアップロードすれば計測が始まります。

    アカウント : adachi1demo
    管理画面   : https://adachi1demo.goatcounter.com
    設定箇所   : index.html 20788行目  var GC_CODE = 'adachi1demo';

  ※ 別のアカウントに変えたい場合は、上記1行を書き換えてください
  ※ 空文字 '' にすると計測処理は一切動きません（外部通信もしません）

【注意】localhost では計測されません
  GoatCounterは開発中のアクセスを数えない仕様のため、
  手元のPCで開いても数字は増えません。
  GitHub Pages などに公開してからアクセスすると記録されます。

【記録される内容】
  ・訪問数（自動）
  ・demo-start     … 「出撃する」が押された回数
  ・demo-complete  … 体験版の最終画面に到達した回数
  ダッシュボードの Pages 一覧に、上記2つがイベントとして並びます。
  「出撃したうち何割が最後まで遊んだか」が分かります。

【プライバシー】
  GoatCounterはCookieを使わず、個人を特定する情報も集めません。
  記録されるのは匿名の集計値のみです。
